# Git Collaboration Practice

A hands-on project created as part of the LF 2026 Git Collaboration Challenge.

## Objective

To understand and practice a real-world Git and GitHub workflow, including repository initialization, branching, meaningful commits, pushing changes, and pull requests.

## Concepts Covered

- Git repository initialization
- GitHub repository connection
- Branch creation and management
- Meaningful commit messages
- Remote repository management
- Pull requests and merging
